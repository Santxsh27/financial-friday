BRIEF DESCRIPTION OF YOUR SOLUTION - COPY THE NEXT PARAGRAPH ONLY

Financial Friday is an India-first AI financial buddy that helps people understand their statement history and plan their next financial goal. Users review a supported INR PDF/CSV statement, explore spending visually, and talk to Friday about purchases, savings or an emergency reserve. Gemini on Vertex AI interprets documents and conversational goals, asks for missing facts, and provides contextual explanations. Independent code validates source evidence and calculates allocations, dated milestones, pressure scenarios and feasible alternatives using exact INR arithmetic. Google Cloud Run hosts the responsive web gateway and private Python/FastAPI API. Cloud Firestore stores tenant-private reviewed history, preferences and confirmed roadmaps. Document AI supports OCR for scanned PDFs, while Google Search grounding supplies attributed public research. Optional Gemini transcription and speech make the assistant accessible by voice. Explicit consent, Google sign-in and stale-response checks protect the workspace. The prototype does not connect to a real bank, execute payments or promise investment returns.
